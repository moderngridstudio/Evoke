Size guide

Adds a size guide link beside the matching option, on the product page and inside Quick Look. Pick the page holding your size chart — its content opens in a panel, so the shopper never leaves what they were looking at.

SettingTypeOptionsDefaultNotes
Show size guideOn / offfalseOff until you turn it on, so the example measurements below are never shown to shoppers by mistake.
Size guide pagePageUsed by every product unless one names its own chart in the custom.size_chart metafield. Leave empty to hide the link.
Size option nameTextSizeMust match the product option, for example Size. Case and spacing are ignored.
Link labelTextSize guide
