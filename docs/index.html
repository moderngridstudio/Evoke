What Evoke includes

47 sections, 31 of which you can add to any page from the theme editor. The rest are the fixed parts of specific templates — the header, the footer, the product page's main section, and so on.

Highlights:

  • Collage — a six-block editorial grid mixing images, products, collections, text, video and countdowns
  • Shop the look — one styled photograph with the products in it attached, so a whole outfit or room can be bought from a single image
  • Slideshow — full-bleed hero slides with separate desktop and mobile art, positioning and typography
  • Quick Look — a product modal that opens from any product card, styled once in Theme settings and reused everywhere
  • Featured collection and Featured collection tabs — one collection on its own, or several behind a tabbed strip
  • Blog posts — recent or hand-picked articles, using the same card as the blog template
  • Before/after comparison, Countdown timer, Scrolling banner, Video popup, Social proof, Dynamic text
  • Mega menus — including a collection mega menu that pulls live products from a collection

Built-in Shopify features

Evoke supports these without any app:

  • Customer accounts via the built-in shopify-account component
  • Faceted filtering and sorting on collection and search pages
  • Predictive search
  • Related and complementary product recommendations
  • Local pickup availability
  • Subscriptions (selling plans), unit pricing, variant images
  • 3D models and AR, YouTube and Vimeo, Shopify-hosted video
  • Shop Pay Installments, accelerated checkout buttons, Follow on Shop
  • Country/region and language selectors
  • Image focal points — the focal point you set in Shopify admin is respected wherever images are cropped

Languages

Evoke ships with English, French, German and Spanish.

All customer-facing text is translatable, so any additional language can be added through Shopify's Translate & Adapt app without touching the theme code. Product titles, descriptions and meta text are your own content and are translated in the same app.

Requirements

  • A Shopify plan — no additional apps required
  • Modern browsers: Chrome, Safari, Firefox and Edge (current versions), plus mobile Safari and Chrome

Compatibility note

Evoke uses Shopify's current customer accounts. It does not include the deprecated legacy customer account templates. Publishing Evoke moves your store to the current accounts experience automatically.
